CloudPulse

☁️

A practice dashboard that explores what happens when one web server stops passing its health check.

WHAT I LEARNEDA server can be running but still fail the test that says it is ready for visitors.
TerraformEC2 + ALBLambdaDynamoDB
See how I thought it through ＋

The question: If one server fails its health check, how can the app keep taking requests?

My choice: Put a load balancer in front of servers in two zones. The load balancer checks the servers. Auto Scaling is set up to replace an unhealthy server.

Why use Lambda and DynamoDB? They hold a shared counter that can be used by both servers. The dashboard can still load if the counter has a problem.

What is missing? This practice setup uses public HTTP. Its alerts do not send notifications. I have not confirmed a live AWS deployment, so this page does not claim one.
